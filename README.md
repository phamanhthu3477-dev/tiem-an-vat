# Tiệm ăn vặt giá hạt dẻ

Website tĩnh HTML/CSS/JavaScript, có thể triển khai trực tiếp bằng GitHub Pages.

## Cấu trúc
- `index.html`: trang chính
- `style.css`: giao diện
- `script.js`: chức năng giỏ hàng, lọc, tìm kiếm và đặt hàng
- `images/`: ảnh website

## Đưa lên GitHub Pages
1. Tạo một repository mới trên GitHub.
2. Upload toàn bộ nội dung trong thư mục này.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`.
6. Lưu lại và chờ GitHub Pages triển khai.

Lưu ý: website hiện là frontend tĩnh. Phần "đặt hàng" và giỏ hàng chạy trên trình duyệt; chưa có máy chủ/database để lưu đơn hàng thật.
